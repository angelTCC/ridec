1. DESCRIPCIÓN GENERAL
───────────────────────

RIdeC es una red iberoamericana de estudiantes y profesionales dedicada a
impulsar las ciencias básicas (Física, Matemática, Química, Biología),
reducir la deserción universitaria y generar comunidad científica.

Stack tecnológico:
  - Next.js 16 (App Router)
  - React 19 + TypeScript
  - Tailwind CSS 4
  - Motion (Framer Motion) para animaciones
  - Prisma 6 + SQLite para base de datos

4. COMPONENTES UI REUTILIZABLES
────────────────────────────────

4.1 Button

  Props:
    variant: "primary" | "secondary" | "outline" | "outline-dark" | "ghost"
    size: "sm" | "md" | "lg"
    href?: string (si se provee, renderiza Link en vez de button)
    children: ReactNode

  Ejemplo:
    <Button href="/eventos" variant="primary" size="lg">
      Ver eventos
    </Button>

4.2 SectionHeader

  Props:
    title: string
    subtitle?: string

  Ejemplo:
    <SectionHeader
      title="¿Qué hacemos?"
      subtitle="Comunidades, mentorías e investigación"
    />

4.3 StatCard

  Props:
    number: string
    label: string

  Ejemplo:
    <StatCard number="82.7%" label="Tasa de deserción en Física" />

4.4 FeatureCard

  Props:
    icon: string (emoji o texto)
    title: string
    text: string
    href: string

  Ejemplo:
    <FeatureCard
      icon="🔬"
      title="Comunidades"
      text="Grupos de estudio..."
      href="/nosotros"
    />

4.5 EventCard

  Props:
    tag: "ec" | "gl" (Explorando Ciencias / Generando Lazos)
    tagLabel: string
    date: string
    title: string
    text: string
    img: string (ruta de imagen)

  Ejemplo:
    <EventCard
      tag="ec"
      tagLabel="Explorando Ciencias"
      date="15 Ago 2025"
      title="Taller: Física Cuántica"
      text="Una inmersión práctica..."
      img="/images/bioinformatica.jpg"
    />

4.6 OdsCard

  Props:
    img: string (ruta de imagen ODS)
    title: string
    text: string

  Ejemplo:
    <OdsCard
      img="/images/ODS4.png"
      title="Educación"
      text="Programas abiertos..."
    />

4.7 Slider

  Props:
    children: ReactNode (EventCards u otros)
    visibleCount?: number (default: 3)

  Ejemplo:
    <Slider visibleCount={3}>
      {events.map(ev => <EventCard key={ev.title} {...ev} />)}
    </Slider>

4.8 CTASection

  Props:
    title: string
    text: string
    primaryBtn: { label: string; href: string }
    secondaryBtn?: { label: string; href: string }

  Ejemplo:
    <CTASection
      title="Únete a la red"
      text="Forma parte de una comunidad..."
      primaryBtn={{ label: "Ver oportunidades", href: "/oportunidades" }}
      secondaryBtn={{ label: "Conoce más", href: "/nosotros" }}
    />


5. SECCIONES DE PÁGINA
───────────────────────

Las secciones componen los componentes UI y se encuentran en
src/components/sections/. Cada sección es independiente y reutilizable.

  Sección             Dependencias
  ──────────────────────────────────────────────
  HeroSection         NetworkBackground, Button, motion
  StatsSection        StatCard, motion
  FeaturesSection     SectionHeader, FeatureCard, motion
  EventsSection       SectionHeader, Slider, EventCard, motion
  OdsSection          SectionHeader, OdsCard, motion
  JoinSection         CTASection, motion
  ContactSection      SectionHeader, Contacto, motion

Para agregar una nueva sección:
  1. Crear archivo en src/components/sections/NuevaSeccion.tsx
  2. Componer componentes UI existentes
  3. Importar en src/app/page.tsx


6. PÁGINA PRINCIPAL (page.tsx)
──────────────────────────────

La página principal es un compositor simple (~25 líneas) que ensambla
todas las secciones:

  HeroSection
    ↓
  section-light (contenedor fondo claro)
    ├── StatsSection
    ├── FeaturesSection
    ├── EventsSection
    ├── OdsSection
    ├── JoinSection
    └── ContactSection

No contiene lógica de negocio ni datos hardcodeados.


7. FONDO ANIMADO (NetworkBackground)
─────────────────────────────────────

Componente SVG que renderiza:
  - 28 ciudades在全球 (Europa, Asia, África, América)
  - 34 conexiones animadas con dots viajeros cyan
  - 6 siluetas de continentes
  - Pulso luminoso en cada nodo

Coordenadas: proyección equirectangular
  x = (lng + 180) / 360 * 1000
  y = (90 - lat) / 180 * 500

Para agregar una ciudad:
  1. Agregar objeto al array 'cities' con name, lat, lng, region
  2. Agregar conexiones al array 'connections' con índices [from, to]
  3. Verificar que los índices no excedan la longitud del array


8. FORMULARIO DE CONTACTO
──────────────────────────

  Componente: formulario.tsx
  Endpoint: POST /api/contacto
  Base de datos: SQLite via Prisma

  Campos: nombre (min 2), email (regex), mensaje (min 10)
  Estados: formulario → cargando → éxito/error

  Modelo Prisma (schema.prisma):
    model Contacto {
      id        Int      @id @default(autoincrement())
      nombre    String
      email     String
      mensaje   String
      createdAt DateTime @default(now())
    }


9. CÓMO CAMBIAR EL DISEÑO
───────────────────────────

9.1 Cambiar colores principales:
  → Editar src/styles/theme.css
  → Modificar las variables --c-primary, --c-secondary, --c-accent, etc.
  → Todos los componentes se actualizan automáticamente

9.2 Cambiar tipografía:
  → Editar src/styles/theme.css (variables --font-heading, --font-body)
  → Editar src/app/layout.tsx si necesitas cambiar las fuentes de Google

9.3 Cambiar espaciado general:
  → Editar src/styles/theme.css (variables --sp-xs hasta --sp-2xl)

9.4 Cambiar el estilo de un componente específico:
  → Editar src/styles/components.css
  → Buscar la clase del componente (ej: .stat-card, .feature-card)

9.5 Agregar una nueva página:
  1. Crear directorio en src/app/nuevapagina/
  2. Crear page.tsx dentro
  3. Usar componentes UI y sections existentes

9.6 Agregar un nuevo componente UI:
  1. Crear archivo en src/components/ui/NuevoComponente.tsx
  2. Agregar estilos en src/styles/components.css
  3. Documentar props en documentacion.txt
